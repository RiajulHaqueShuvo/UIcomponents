# UIComponents

A library of animated UI components (text effects, animations, backgrounds, buttons, cards, UI widgets)
with live previews, copy-ready code (React and HTML/CSS/JS), a Pro "Customize" playground, a Color
Palette Studio, and an admin panel with its own Node backend.

## Run locally
```
npm install
npm run admin:create -- you@example.com   # once
npm run dev:all                           # site http://localhost:5620, admin /admin
```
